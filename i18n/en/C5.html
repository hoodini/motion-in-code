The catalog is built on HTML and seek(t). Here are the tools that do the same job differently, and when each one wins.

How to choose, in four questions

  1. One film or a hundred? One: HTML and seek(t). A hundred from the same template: Remotion or HyperFrames.
  2. Is there a ready-made animation from a designer? Lottie fits into any of these approaches.
  3. Does it live inside an app and react to the user? Rive. At that point it's no longer a video question.
  4. Need a custom 3D model? Blender or Spline, export to GLTF, and bring it into three.js.

Prompt builder

Start from a preset, lay the scenes out on the beat grid, and get one complete prompt for the whole film. Save and share it with a link.

There's no AI here. The builder assembles the prompt from fixed parts, so it's easy to see exactly which sentence each choice adds. It follows the six blocks:

  1. Start from a preset: an app launch, zero-style food ordering, a physical product or a data film. Each preset fills every field, and everything stays editable.
  2. The story, format, tempo and branding go into <direction>. The sentence about the film goes into the prompt word for word.
  3. The elements: each catalog element adds a line to every block: what to see, how to build it in <build>, and which bug to warn about in <gotchas>. The builder also sums up which engines the film needs (Canvas, three.js, WebGPU) and adds the WebGPU flags when they're needed.
  4. The scenes are <structure>: each scene has a name, a number of beats, the on-screen text, an element, and how it is born from the one before. We mark the scene where the drop lands, and the film's length is the sum of the beats. Moving the length slider stretches all the scenes together.
  5. How things become each other: the motion verbs and camera moves from the interface dictionary, one signature trick, and the banned list.
  6. Saving: the builder remembers what we built in this browser, "Copy a link" stores every choice inside the address so we can come back to it or send it to someone, and "Download as a file" saves the prompt as text.
